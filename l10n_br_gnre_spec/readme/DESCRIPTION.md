Modelos abstratos (mixins) da GNRE (Guia Nacional de Recolhimento de Tributos
Estaduais), gerados por [xsdata-odoo](https://github.com/akretion/xsdata-odoo) a
partir dos XSD oficiais.

Os schemas vêm do pacote do Manual de Integração do Contribuinte v2.15,
distribuído pelo portal GNRE. São 16 XSD, cobrindo o lote de envio, o resultado,
a consulta, o retorno e a configuração por UF.

Este módulo é 100% gerado e não tem regra de negócio, seguindo o mesmo padrão de
`l10n_br_nfe_spec`, `l10n_br_cte_spec` e `l10n_br_mdfe_spec`. A implementação
fica no módulo `l10n_br_gnre`.
