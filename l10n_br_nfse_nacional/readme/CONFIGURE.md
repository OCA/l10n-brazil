On the company, set:

- the ICP-Brasil **A1 certificate** (module `l10n_br_fiscal_certificate`);
- **E-doc Processor** = Odoo Community (`processador_edoc = oca`);
- **NFSe Provider** = Sefin Nacional (ADN) (`provedor_nfse = nacional`);
- **NFSe Environment** = Produção or Homologação, which the ADN calls produção
  restrita. The document copies it on creation and you can override it there.
