Este módulo depende de:

* `l10n_br_fiscal_dfe`
* `l10n_br_nfse`
* `l10n_br_fiscal_certificate`

A empresa precisa de um certificado e-CNPJ A1 válido, o mesmo já utilizado pela localização fiscal.
