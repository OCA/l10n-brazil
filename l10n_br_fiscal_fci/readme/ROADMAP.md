- A transmissão do arquivo não é automatizada: ele deve ser validado e
  transmitido com o aplicativo *Validador/Transmissor* da SEFAZ, que é um
  programa Windows (não existe web service para a FCI).
- O número de controle da FCI ainda não é gravado na NF-e: o campo `nFCI`
  (grupo I07 do leiaute da NF-e) continua como TODO do módulo `l10n_br_nfe`.
- As mercadorias não são preenchidas automaticamente a partir dos documentos
  fiscais do período; os valores são informados pelo usuário.
