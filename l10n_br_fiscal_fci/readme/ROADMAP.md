- A transmissão do arquivo não é automatizada: o arquivo deve ser validado
  e transmitido com o aplicativo *Validador/Transmissor* da SEFAZ, que é um
  programa desktop para Windows (não existe web service para a FCI).
- O número de controle da FCI ainda não é informado na NF-e: o campo `nFCI`
  (grupo I07 do leiaute da NF-e) ainda é um TODO do módulo `l10n_br_nfe`.
- As linhas de mercadorias não são preenchidas automaticamente a partir dos
  documentos fiscais do período, os valores devem ser informados pelo
  usuário.
