On any fiscal document line, next to each tax field a manual base and a manual value
field are shown:

- Leave both empty: the tax is calculated automatically, as before.
- Fill in the manual base: the tax value is recalculated from that base.
- Fill in the manual value: it directly overrides the calculated tax value.

The manual fields are only shown when the line's fiscal operation line has "Allow Manual
Tax Override" enabled. This only hides the fields to reduce visual clutter: a manual
value set while the option is disabled still overrides the calculated tax value.
