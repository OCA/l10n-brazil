This module allows manually overriding the base and/or value of any
Brazilian fiscal tax (ICMS, ICMS ST, ISSQN, ISSQN RET, IPI, II, PIS, PIS
ST, PIS RET, COFINS, COFINS ST, COFINS RET, CSLL, CSLL RET, IRPJ, IRPJ
RET, INSS, INSS RET, CBS, IBS) on a fiscal document line.

Usage
=====

On any fiscal document line, next to each tax field a manual base and a
manual value field are shown:

- Leave both empty: the tax is calculated automatically, as before.
- Fill in the manual base: the tax value is recalculated from that base.
- Fill in the manual value: it directly overrides the calculated tax
  value.

Known issues / Roadmap
======================

- A manual value of exactly 0 (zero) is treated as "not set", since 0 is
  falsy in Python/Odoo. It is currently not possible to force a tax
  value to zero through the manual value field; use the manual base
  field with a rate-based tax instead.
