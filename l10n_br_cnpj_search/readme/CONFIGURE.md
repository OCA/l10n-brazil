Esta busca de informações a partir do cnpj é realizada com base no
provedor configurado na aba de configurações, vale ressaltar que o
provedor receitaws permite a realização de três consultas por minuto,
o OpenCNPJ é gratuito e não exige autenticação, servindo os dados a
partir de um snapshot público da Receita publicado periodicamente
(não é uma consulta em tempo real), enquanto que o SERPRO é pago e
permite consultas ilimitadas em seus planos.
