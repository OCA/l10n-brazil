This module quotes shipping through
`Frenet <https://www.frenet.com.br>`__, the Brazilian shipping gateway:
the checkout offers one delivery option per service enabled in the
Frenet account (Correios PAC, Sedex, Jadlog and so on), each with its
real price and estimated delivery time, so the customer picks the best
one.

It also follows the shipment: the tracking events of
``/tracking/trackinginfo`` feed the delivery states of the
``delivery_state`` module, whose scheduled action keeps the pickings up
to date and can notify the customer on delivery.

The public Frenet API does not register shipments nor emit transport
labels: the label is printed at the Frenet panel and the tracking number
is then typed into the picking.

Configuration
=============

1. Create a delivery method in *Inventory > Configuration > Delivery
   Methods* with provider *Frenet*, and fill the Frenet token (Painel
   Frenet > Integrações) and the dimensions of the box the orders ship
   in.
2. Press *Synchronize Frenet Services*: one delivery method is created
   per service enabled in the Frenet account.
3. Publish on the website the services the customer may choose.

The quote weighs the products of the order (minimum 50 g), so set the
weight on the products.

Usage
=====

At the checkout the customer sees one option per published Frenet
service, with the price and the estimated delivery time returned by
Frenet for their ZIP code.

After registering the shipment at the Frenet panel and printing the
label there, type the tracking number into the delivery order. The
*Update delivery states* scheduled action of the ``delivery_state``
module then follows the tracking events, and the tracking link of the
picking points to the Frenet public tracking page.

For the fiscal label glued on the package handed to Correios or the
other delivery services, print the *DANFE Simplificado - Etiqueta* of
the NF-e (see the ``l10n_br_nfe`` module), made for the same 100 x 150
mm thermal label paper.

Known issues / Roadmap
======================

- Quote each product with its own dimensions (today the order ships in a
  single box configured on the delivery method).
- Register the shipment and print the transport label from Odoo, if
  Frenet exposes an API for it.
