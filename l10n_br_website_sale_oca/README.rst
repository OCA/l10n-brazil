Installation
============

This module depends on:

- website_sale
- l10n_br_sale
- l10n_br_portal

Configuration
=============

Set the website's company country to Brazil to enable the localized
checkout. Brazilian billing addresses require a CPF or CNPJ even if the
default B2B checkout fields are disabled. Foreign addresses use Odoo's
regular checkout fields.

Usage
=====

Choose Brazil in the checkout address. Enter a CEP to look up the
street, district, state and city. If the lookup is unavailable, fill
those fields manually. Enter the street number and, for billing, a valid
CPF or CNPJ. State and municipal tax registrations are available when a
company name is provided.
