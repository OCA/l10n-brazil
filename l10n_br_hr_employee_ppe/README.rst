This module adds automatic lookup of PPE Certificates of Approval (CA)
from the Brazilian Ministry of Labor (MTE) public database.

The MTE publishes a daily export of every CA ever issued (approximately
42 000 unique certificates). A scheduled action downloads this file,
parses and deduplicates it, and upserts the results into a local
``caepi.certificate`` table.

When a PPE product's CA number is filled in, the system automatically
populates the certificate expiry date, equipment description,
manufacturer and current MTE status (Valid / Expired / Suspended /
Cancelled).

Configuration
=============

After installation:

1. Navigate to **Settings > Technical > Parameters > System
   Parameters**.
2. The FTP URL defaults to the MTE public server. If you need to
   override it, set the key ``l10n_br_hr_employee_ppe.caepi_ftp_url`` to
   the desired URL.
3. Go to **Settings > Technical > Scheduled Actions** and activate
   **CAEPI: Refresh CA Database (MTE)**. The default interval is daily.
4. Run the action manually once to populate the local database.

Usage
=====

Once the scheduled action has run at least once:

- Open any PPE product and enter a CA number. The expiry date, equipment
  description, manufacturer and MTE status are filled in automatically.
- If the CA has a status other than *Valid*, a warning is shown.
- If the CA is not found in the local database, a warning suggests
  running the sync or checking the number.

To browse or search all certificates, go to **HR > Configuration >
Certificates of Approval (CA)**.

To trigger a manual refresh, open the certificate list view and use the
action **Refresh CAEPI Database (MTE)**.
