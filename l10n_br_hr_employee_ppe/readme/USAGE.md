Once the scheduled action has run at least once:

- Open any PPE product and enter a CA number. The expiry date, equipment
  description, manufacturer and MTE status are filled in automatically.
- If the CA has a status other than *Valid*, a warning is shown.
- If the CA is not found in the local database, a warning suggests running
  the sync or checking the number.

To browse or search all certificates, go to
**HR > Configuration > Certificates of Approval (CA)**.

To trigger a manual refresh, open the certificate list view and use the
action **Refresh CAEPI Database (MTE)**.
