Este módulo é utilizado como dependência por módulos de integração de NFS-e Nacional.
Não possui interface de usuário própria.

Desenvolvedores que precisam montar o payload DPS podem utilizar o ``DpsBuilder`` a
partir de um documento fiscal ``l10n_br_fiscal.document``. Consulte o módulo
``l10n_br_nfse_nacional`` para a integração completa com a API SEFIN.
