- Open *Invoicing > Vendors > DDA Boletos*. The filters (My queue today, Without
  title, Amount divergence, Suspects, Due in 7 days, Overdue) are in the search
  box.
- Each line shows the recommended action. Select several lines and use
  *Action > Apply recommended actions* to apply them in a batch.
- *Link to a title* compares the boleto with each candidate (CNPJ, amount, due
  date and document number) and links one title or several installments of the
  same vendor whose sum is the amount of the boleto.
- *Undo* reverts the last action while the boleto is not in a payment order
  already exported.
- Add the linked boletos to the payment order; the payment line carries the
  digitable line, the bar code and the interest, fine and discount. The title is
  settled by the return of the payment file or by the bank statement, never by
  the DDA event *paid*.
- *Invoicing > Vendors > Import DDA file* reads a return file with a DDA
  structure.
