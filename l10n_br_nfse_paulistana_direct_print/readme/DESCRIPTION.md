Este módulo estende o `l10n_br_nfse_paulistana` adicionando um botão que abre a
NFS-e diretamente no site da Prefeitura de São Paulo, em vez de gerar o PDF pelo
Odoo.

O DANFSE renderizado pelo Odoo é uma representação do documento; o espelho
publicado pela prefeitura é a versão oficial, e é o que os tomadores costumam
pedir. Com este módulo, para documentos da Paulistana o botão "Visualizar PDF"
dá lugar a "Visualizar NFS-e Paulistana", que abre o espelho oficial.
