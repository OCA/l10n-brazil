Você pode criar documentos fiscais direitamente pelo menu fiscal, mas a
princípio você vai pilotar a criação de documentos fiscais a partir dos
invoices Odoo, usando módulos adicionais como l10n_br_account,
l10n_br_sale, l10n_br_purchase...

Na linha da operação fiscal, o campo "Include other values in tax base" define se
frete, seguro e outras despesas entram na base de cálculo. Com "Defined In Tax" vale a
configuração de cada grupo de imposto. Com "Include" ou "Do not Include" a escolha vale
para todos os impostos da linha: com "Do not Include" esses valores saem também da base
do ICMS e do IBS/CBS, e com "Include" entram também na base do ISSQN e das retenções.
